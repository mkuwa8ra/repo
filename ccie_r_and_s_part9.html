Chapter 20: IP Version 6

IPv6は128ビットのアドレス空間を持ち、IPv4の限界を克服するために設計されました。基本的な概念はIPv4と共通していますが、アドレッシングの形式や隣接関係の構築方法に大きな違いがあります [1, 2]。

1. IPv6 アドレッシングとアドレスタイプ

1.1 表記と省略ルール

16ビットごとの8つのグループをコロンで区切って16進数で表記します [2]。

  • 先頭の0の省略: 各グループの先頭にある「0」は省略可能です [3]。
  • 「::」による省略: 「0」が連続するグループは「::」で一度だけ置換できます [4]。

1.2 主要なアドレスタイプ [5, 6]

タイププレフィックス説明
グローバルユニキャスト2000::/3インターネットでルーティング可能な一意のアドレス。
リンクローカルFE80::/10同一リンク内でのみ有効。ルーターによって転送されません [7, 8]。
マルチキャストFF00::/8特定のグループ宛。IPv6にはブロードキャストが存在しません [9, 10]。
エニーキャストユニキャストと同じ複数のデバイスに同一アドレスを付与し、最短の1台に届けます [11]。

1.3 EUI-64 フォーマット

MACアドレス（48ビット）からインターフェースID（64ビット）を自動生成する手法です [12, 13]。

  1. MACアドレスの中央に FFFE を挿入します。
  2. 先頭から7ビット目（U/Lビット）を反転させます（「0」なら「1」にする）。

2. 基本プロトコルと近隣探索 (ND)

IPv6はARPの代わりに、ICMPv6を利用した近隣探索プロトコル (Neighbor Discovery: ND) を使用します [14, 15]。

  • Router Solicitation (RS): ホストがルーターを探すために送信（FF02::2宛）[16, 17]。
  • Router Advertisement (RA): ルーターが自身の存在やプレフィックス情報を通知（FF02::1宛）[16, 18]。
  • Neighbor Solicitation (NS): 隣接機器のMACアドレス解決や重複アドレス検出 (DAD) に使用 [15]。
  • Neighbor Advertisement (NA): NSに対する応答 [15, 17]。

3. IPv6 ユニキャストルーティング

3.1 OSPFv3 [19-22]

  • リンクベース: サブネットではなく「リンク」に基づいて動作します。
  • 新しいLSA: リンクローカルアドレスを通知する Type 8 (Link LSA) や、エリア内のプレフィックスを通知する Type 9 (Intra-Area Prefix LSA) が追加されました。
  • インスタンスID: 同一リンク上で複数のOSPFプロセスを個別に実行可能です。

3.2 EIGRP for IPv6 [19, 23-25]

  • プロセスの有効化: デフォルトでは shutdown 状態のため、no shutdown コマンドが必要です。
  • ルーターID: 32ビット（IPv4形式）のルーターID設定が必須です。
  • クラスレス専用: 階層的なアドレッシングに基づいているため、auto-summary の概念がありません。

4. トンネリング技術 [26-28]

IPv4ネットワーク越しにIPv6通信を運ぶための主な手法です。

  • 手動設定トンネル: ポイントツーポイント。両端でIPv4/IPv6のデュアルスタックが必要です [29]。
  • 6to4 トンネル: ポイントツーマルチポイント。2002::/16 アドレス空間を使用します [30, 31]。
  • ISATAP: サイト内での自動トンネル。ホストとルーター間の接続に適しています [32]。

基本設定コマンド例

! IPv6ルーティングのグローバル有効化
ipv6 unicast-routing

! インターフェースでのアドレス設定（EUI-64利用）
interface GigabitEthernet0/1
 ipv6 address 2001:DB8:1:1::/64 eui-64

! OSPFv3の設定
interface GigabitEthernet0/1
 ipv6 ospf 1 area 0
ipv6 router ospf 1
 router-id 1.1.1.1

! EIGRP for IPv6の設定
interface GigabitEthernet0/1
 ipv6 eigrp 100
ipv6 router eigrp 100
 router-id 2.2.2.2
 no shutdown

! IPv6 ACLの設定と適用
ipv6 access-list MY_ACL
 deny tcp any any eq 80
 permit ipv6 any any
interface GigabitEthernet0/1
 ipv6 traffic-filter MY_ACL in
