Chapter 15: Wide-Area Networks

この章では、WANで最も一般的に使用されるデータリンク層プロトコルであるPPPとフレームリレーについて詳しく学びます [1]。

1. Point-to-Point Protocol (PPP)

PPPは、同期および非同期リンクをサポートし、エラー回復や認証などの豊富な機能を備えた標準プロトコルです [2, 3]。

  • LCP (Link Control Protocol): レイヤ3プロトコルに依存しない機能を制御します。主な機能には、リンク品質監視 (LQM)、ループ検出 (Magic Number)、マルチリンクPPP (MLP)、および認証 (PAP/CHAP) があります [3, 4]。
  • NCP (Network Control Protocol): 特定のレイヤ3プロトコル（IP用のIPCPなど）の機能を制御します [3]。
  • 認証 (Authentication): CHAPは、パスワードをネットワーク上にプレーンテキストで流さないため、PAPよりも安全です [4, 5]。
  • Multilink PPP (MLP): 複数の物理的なシリアルリンクをレイヤ2で1つに束ね、負荷分散を行います [6]。
  • MLP LFI (Link Fragmentation and Interleaving): 大きなデータパケットを断片化し、その間に音声パケットなどを割り込ませることで、低速リンクでの遅延を軽減します [7, 8]。
  • 圧縮 (Compression): PPPはペイロード圧縮 (Stacker, Predictorなど) や、TCP/RTPヘッダー圧縮をサポートしています [9-11]。

2. フレームリレーの概念

フレームリレーは仮想回線 (VC) を使用してデバイス間を接続するパケットスイッチング技術です [12]。

  • DLCI (Data Link Connection Identifier): 各VCを識別するローカルに有意な番号です [12, 13]。
  • LMI (Local Management Interface): ルーターとフレームリレースイッチ間の管理メッセージです。Cisco、ANSI、ITU (q933a) の3種類があり、通常は自動検知されます [14, 15]。
  • カプセル化の種類: Cisco独自のヘッダーと、RFC 2427に基づくIETF標準ヘッダーがあります [16, 17]。
  • 輻輳通知ビット:
    • FECN (Forward Explicit Congestion Notification): 受信方向に輻輳が発生していることを通知します [18, 19]。
    • BECN (Backward Explicit Congestion Notification): 送信方向に輻輳が発生していることを通知します。ルーターはこれを受けて送信レートを下げる（適応型シェイピング）ことができます [18, 19]。
    • DE (Discard Eligibility): 輻輳時に優先的に破棄してよいフレームであることを示します [20, 21]。

3. フレームリレーの設定と高度な機能

  • DLCIの関連付け: frame-relay interface-dlci コマンドを使用してDLCIをサブインターフェースに関連付けます [22, 23]。
  • ペイロード圧縮: パケット単位、データストリーム、およびFRF.9圧縮をサポートしています [24, 25]。
  • FRF.12 断片化: フレームリレー上でのLFIを実現します。これにはFRTS（Frame Relay Traffic Shaping）が必要な「レガシー方式」と、物理インターフェースで直接設定する「インターフェース断片化方式」があります [26, 27]。
  • LFI using MLP over Frame Relay: フレームリレー回線上でPPPヘッダーを使用し、MLPのLFI機能を活用する高度な構成です。ATMとフレームリレーの相互接続環境などで使用されます [28]。

基本設定コマンド例

! PPPとCHAP認証の設定
interface Serial0/1/0
 encapsulation ppp
 ppp authentication chap
 ppp quality 80
!
! マルチリンクPPPの設定
interface Multilink1
 ip address 10.1.34.3 255.255.255.0
 ppp multilink
 ppp multilink group 1
!
! フレームリレーの基本設定（ポイントツーポイント）
interface Serial0/0/0
 encapsulation frame-relay
interface Serial0/0/0.14 point-to-point
 ip address 10.1.14.1 255.255.255.0
 frame-relay interface-dlci 104 IETF
