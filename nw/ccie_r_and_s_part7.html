Chapter 18: Security

ネットワークセキュリティは、デバイスへのアクセス制御（管理プレーン）、スイッチ内でのトラフィック保護（レイヤ2）、およびルーティングやファイアウォールによる制御（レイヤ3）の多層防御によって構築されます [1]。

1. デバイスアクセスとAAA

  • パスワード保護:
    • service password-encryption: 設定内の平文パスワードを「タイプ7」で暗号化しますが、これは比較的脆弱です [2, 3]。
    • enable secret: MD5ハッシュを使用してパスワードを保存するため、より安全です [4]。
  • SSH (Secure Shell): Telnetの代替として、管理セッションを暗号化します。設定にはホスト名、ドメイン名、RSAキーの生成が必要です [5, 6]。
  • AAA (Authentication, Authorization, and Accounting):
    • TACACS+: TCPポート49を使用。パケットペイロード全体を暗号化し、コマンド単位の認可に優れています [7, 8]。
    • RADIUS: UDPポート1812/1645を使用。パスワードのみを暗号化します [8]。
    • メソッドリスト: 複数の認証手段（RADIUSサーバー、ローカルDB、パスワードなしなど）を順番に試行するように構成できます [9, 10]。

2. レイヤ2 セキュリティ (スイッチセキュリティ)

キャンパスネットワーク内のポートを保護するための主要な機能です [11]。

  • ポートセキュリティ: MACアドレスの最大数を制限し、不正なMACからの通信を遮断します。「スティッキー（Sticky）」学習により、動的に学習したアドレスを構成に保存可能です [12, 13]。
  • DHCPスヌーピング: 信頼できないポートからの不正なDHCPサーバーメッセージを遮断し、IP/MACのバインディングデータベースを構築します [14, 15]。
  • Dynamic ARP Inspection (DAI): DHCPスヌーピングのデータベースを使用して、不正なARPメッセージ（中間者攻撃）をフィルタリングします [16, 17]。
  • IP Source Guard: 送信元IPアドレスをスヌーピングデータベースと照合し、IPスプーフィングを防ぎます [18]。
  • IEEE 802.1X: EAPプロトコルを使用してポートベースのユーザー認証を行います。サプリカント（端末）、オーセンティケータ（スイッチ）、認証サーバー（RADIUS）の3要素で構成されます [19, 20]。

3. レイヤ3 セキュリティ (ルーターセキュリティ)

  • uRPF (Unicast Reverse Path Forwarding): 受信パケットの送信元IPへのルートが受信インターフェースと一致するかを確認し、スプーフィングされたパケットを破棄します（厳密モードと緩和モードがあります） [21, 22]。
  • TCP Intercept: TCP SYNフラッド攻撃からサーバーを保護します。ルーターがコネクション要求を監視またはプロキシとして代行します [6, 23]。
  • ファイアウォール機能:
    • CBAC (Classic IOS Firewall): ステートフルインスペクションを行い、内部から開始されたセッションに対する戻りトラフィックを動的に許可します [24, 25]。
    • Zone-Based Firewall (ZFW): インターフェースを「ゾーン」に分割し、ゾーンペアに対してポリシーを適用する現代的な手法です [26, 27]。
  • CoPP (Control Plane Policing): ルーターのCPU（コントロールプレーン）宛のトラフィックを制限し、DoS攻撃による過負荷から保護します [28, 29]。

基本設定コマンド例

! AAAの設定
aaa new-model
aaa authentication login default group tacacs+ local
tacacs-server host 10.1.1.100 key cisco_key

! ポートセキュリティの設定
interface fa0/1
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address sticky
 switchport port-security violation shutdown

! uRPFの設定
interface gig0/1
 ipv6 verify unicast source reachable-via rx

! ゾーンベースファイアウォール（ゾーン定義）
zone security INSIDE
zone security OUTSIDE
zone-pair security IN-TO-OUT source INSIDE destination OUTSIDE
