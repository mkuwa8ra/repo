1. FortiSASEとは

FortiSASEは、Fortinet社がクラウド上で提供するSASE（Secure Access Service Edge）セキュリティサービスです。場所に関係なくどこからアクセスしても、会社の社内LANと同等のセキュリティポリシーで保護できます。セキュリティとネットワーキングのシームレスな統合により、すべてのユーザーに同じレベルの保護・可視性・ユーザーエクスペリエンスを提供します。

✓ 99.999% SLA（レイテンシ保証付き）— 世界数百のセキュリティPoPs

3. SASEコンセプト比較とFortiSASEの立ち位置

📘 Forrester社モデル（FortiSASEのベース）

オンプレミスのUTM（FortiGate）とクラウドのSASEを融合してセキュリティを提供。既存のFortiGate資産を活用しながらZTNA機能を追加可能。

FortiSASEの推奨構成: FortiGate + FortiSASE連携でZTNA/SPAを実現

📗 Gartner社モデル（SSE単体利用も可能）

クラウドのSASEのみでセキュリティを提供する構成。FortiGate未導入の場合、FortiSASE単体でSSE（Security Service Edge）として利用可能。

FortiSASE単体: SSEとしてSIA + SSA + エンドポイントセキュリティを提供

4. 接続モード

エンドポイントモード

FortiClientによるVPNを介してFortiSASEに接続。すべてのインターネット通信がFortiSASEによって保護されます。

  • フルトンネル方式
  • ポスチャーチェック対応
  • エンドポイントセキュリティ統合

SWG（セキュアWebゲートウェイ）モード

WebブラウザのWebプロキシとしてFortiSASEを使用。Webブラウザの通信のみFortiSASEによって保護されます。

  • エージェントレス（ブラウザ設定のみ）
  • Web通信に限定した保護
  • BYOD端末に最適

5. コア機能群

🔒 Secure Internet Access (SIA)

インターネットアクセス時の脅威保護

  • アンチウイルス
  • Web / DNSフィルタ
  • 侵入防止（IPS）
  • ファイル / ビデオフィルタ
  • アプリケーション制御
  • SSLインスペクション
  • Remote Browser Isolation (RBI) ※Advanced以上

☁️ Secure SaaS Access (SSA)

SaaSアプリの包括的な可視化と制御

  • データ漏洩防止（DLP）
  • CASB（Cloud Access Security Broker）
  • シャドーIT検出
  • SaaS使用状況の把握
  • 機密情報・重要データの保護

🏢 Secure Private Access (SPA)

社内リソースへのセキュアアクセス

  • ゼロトラストネットワークアクセス（ZTNA）
  • セキュアプライベートアクセス（SPA）
  • FortiGate連携必須
  • IPsec VPN + BGP動的ルーティング
  • Split DNS対応

💻 Endpoint Security

端末のセキュリティ保護（FortiClient必須）

  • アンチウイルス
  • アンチランサムウェア
  • 脆弱性スキャン
  • リムーバブルメディア制御
  • サンドボックス

7. SD-WAN & ネットワーク機能

🌐 SD-WAN / ADVPN

  • Built-in SD-WAN: 唯一のSASEクラウドに内蔵されたSD-WAN機能
  • ADVPN: 動的トンネル機能でメッシュ型接続
  • 3rd Party IPsec: 非Fortinet機器からBranch On-ramp PoPsへの標準IPsec接続対応
  • WAN負荷分散: SaaS/Internet向け通信をFortiSASE経由にルーティング

🌍 Geofencing & アクセス制御

  • 国/地域に基づくリモートユーザー接続の許可/ブロック
  • エッジデバイス接続のジオフェンシング制御
  • デフォルト: Country/Region = Deny、選択なし → 制限なし
  • インフラストラクチャベースのフィルタリング

10. FortiSASEの差別化ポイント

🔄 WAN回線の負荷分散

Internet / SaaS / パブリッククラウド向け通信をFortiSASE経由にし、WAN回線の負荷を最適化。SD-WAN + ADVPNによる動的トンネルを内蔵。

🛡️ どこからでも安全

FortiSASEのセキュリティサービスにより、場所を問わず端末を保護。AI/ML駆動FortiGuardサービスでゼロデイ脅威も防御。

🏢 社内システムへ選択接続

ZTNA / SPA機能により、必要な社内システムのみ本社経由で通信。ポスチャーチェックでゼロトラストを実現。

12. ポスチャーチェック（ゼロトラスト）

FortiClientがエージェントとして端末の「状態（ポスチャー）」をFortiSASEに送信し、認証だけでなく端末の状態に基づいてアクセスの許可/拒否を制御します。
