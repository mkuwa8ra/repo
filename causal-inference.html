CASE FILE

因果推論

「たまたま一緒に起きた」と「たしかに引き起こした」を、探偵になって見分けよう

世の中には「AとBが同時に増えている」現象がたくさんある。でも、それだけでは「Aが原因でBが起きた」とは言い切れない。 このページでは、探偵が事件の真犯人をつきとめるように、「本当の原因」を見つける考え方＝因果推論（いんがすいろん）を、 小学生にもわかる例から、大人が仕事や研究でも使えるレベルまで、順番に解き明かしていく。 上のスイッチで「やさしい」と「くわしい」を切り替えられる。

FILE 01 ／ 相関と因果

「一緒に増えている」＝「原因」ではない

毎年、アイスクリームがよく売れる日ほど、プールでおぼれる事故も増える、というデータがある。 では「アイスクリームを食べると、おぼれやすくなる」と言えるだろうか？　もちろん、そんなはずはない。

本当の原因は「気温が高い日」だ。暑い日はアイスが売れるし、暑い日はプールに行く人も増えて事故も増える。 アイスと事故は「一緒に動いている」だけで、どちらも気温という別の原因のせいで増えているにすぎない。

このように、2つのことが同時に変化する関係を「相関」と呼び、片方が本当にもう片方を引き起こす関係を「因果」と呼ぶ。 相関があるからといって、因果があるとは限らない。これが因果推論の出発点だ。

たとえ話：探偵が「事件現場に黒猫がいた事件が多い」と気づいても、「黒猫が犯人だ」とはならないよね。たまたま同じ時間帯にうろついていただけかもしれない。相関は"あやしい手がかり"であって、"証拠"そのものではない。
🔍 スイッチを「くわしい」にすると、統計用語での説明が読めます
🔍 くわしく（おとな向け）

統計的には、2変数 X と Y の相関は「共分散」や「相関係数」で測られ、両者が同じ方向・逆方向に動く度合いを示す。 しかし相関係数がどれほど高くても、それは因果関係の証明にはならない。この現象は疑似相関（spurious correlation）と呼ばれ、 多くの場合、両方の変数に影響を与える共通原因（交絡因子）が背後に存在する。

現代の因果推論では、変数間の関係を矢印で描く因果グラフ（DAG：有向非巡回グラフ）を使って、 「相関はあるが因果はない経路」と「本当の因果の経路」を図で区別する手法がよく使われる。 アイスクリームの例では、気温 → アイスの売上、気温 → 事故数、という2本の矢印だけがあり、アイスの売上 → 事故数、という矢印は存在しない。

FILE 02 ／ 交絡因子

事件の裏にひそむ「かくれた黒幕」

「家に本をたくさん持っている子どもは、テストの点数が高い」というデータがあるとする。 だからといって、本をたくさん買えば成績が上がる、と単純には言えない。

実際には「親が教育に熱心で、収入にも余裕がある家庭」という、隠れた要因が関係しているかもしれない。 そういう家庭は本もたくさん買うし、勉強のサポートも手厚いので、成績も自然と上がりやすい。 この「本の多さ」と「成績」の両方に影響している、目に見えにくい原因のことを交絡因子（こうらくいんし）と呼ぶ。

因果推論のいちばん大事な仕事は、このかくれた黒幕を見つけて、その影響を取りのぞいてから、本当の関係を調べることだ。

🔍 「くわしい」モードで、交絡因子を数式的にどう扱うかを見られます
🔍 くわしく（おとな向け）

交絡因子 Z は、原因候補 X（本の冊数）と結果 Y（成績）の両方に影響する変数で、 DAGでは X ← Z → Y という「バックドアパス」を作る。この経路を通じて生まれる見かけの関連を取り除くには、 Z の値ごとにデータを分けて分析する（層別化）、回帰分析で Z を統制変数として入れる、 あるいは傾向スコアマッチング（Propensity Score Matching）で Z の条件が近い個体同士を比較する、といった方法が使われる。

重要なのは、交絡因子は「測定されているとは限らない」という点だ。親の教育熱心さのように定量化しにくい要因（未観測交絡）が残っていると、 どれだけ統計的に調整してもバイアスが取り切れない場合がある。これが後述するランダム化比較試験が重視される理由の一つになる。

FILE 03 ／ 逆の因果

矢印の向き、逆じゃない？

「運動をよくする人は健康だ」というデータを見て、「じゃあ運動すれば健康になる」と考えるのは自然に思える。 でも、実は逆かもしれない――「もともと健康な人だから、体力があって運動できる」という可能性もある。

原因と結果を取り違えると、まったく逆の対策をしてしまうことがある。 探偵の仕事でいえば「犯人が現場に来たから足跡が残った」のか「足跡があったから、あとで誰かが来た」のか、順番を間違えないようにするのと同じだ。

身近な例：「成功している会社ほど、社員が朝早く出社する」→ だから早起きすれば成功する、とは限らない。忙しくて仕事量が多い会社だから早く来ている、という逆の流れかもしれない。
🔍 「くわしい」モードで、逆因果を見抜く統計的な工夫を紹介します
🔍 くわしく（おとな向け）

逆因果（reverse causality）は、横断的な1時点のデータだけでは見抜きにくい。対策としては、 時間の前後関係が明確なパネルデータ（同じ対象を複数時点で追跡したデータ）を使い、 「先に起きた出来事」だけを原因候補として扱う方法がある。

経済学などで使われるグレンジャー因果性（Granger causality）は「Xの過去の値がYの将来の値の予測に役立つか」を検定する手法だが、 これはあくまで「予測力があるか」を測るものであり、真の因果関係を証明するものではない点に注意が必要。

FILE 04 ／ 最強の武器

くじ引きで比べる：ランダム化比較試験

本当の原因を見つける、いちばん確実な方法は「くじ引きで2つのグループに分けて比べる」ことだ。 たとえば新しい薬の効果を調べたいとき、参加者をくじ引きでランダムに2グループに分け、 片方には本物の薬、もう片方には偽薬（見た目だけ同じもの）を渡して、結果を比べる。

くじ引きでランダムに分けているので、年齢や体質、生活習慣などの違いは、両方のグループにだいたい同じくらい散らばる。 だから、あとで結果に差が出たら「薬のちがい以外に理由が見当たらない」＝薬が原因だと、自信を持って言える。 これをランダム化比較試験（RCT）と呼び、因果推論における"ゴールドスタンダード（黄金基準）"とされている。

🔍 「くわしい」モードで、RCTの理論的な背景を紹介します
🔍 くわしく（おとな向け）

RCTの理論的基盤は、統計学者ドナルド・ルービンらが整理した潜在アウトカムフレームワーク（Rubin Causal Model）にある。 個人 i について、処置を受けた場合の結果 Y₁ᵢ と受けなかった場合の結果 Y₀ᵢ を考え、 真の因果効果は Y₁ᵢ − Y₀ᵢ だが、現実には同じ人が同時に両方を経験することはできない（因果推論の根本問題）。

ランダム化によって、処置群と対照群の潜在アウトカムの分布が期待値として等しくなるため、 グループ間の平均の差（平均処置効果 ATE：Average Treatment Effect）を、個人レベルでは観測できない因果効果の推定値として使える。

  • 内的妥当性：ランダム化のおかげで交絡因子の影響を排除しやすい
  • 外的妥当性：実験の対象者や状況が、実際に適用したい現実の集団とどれだけ似ているか、は別問題として残る
FILE 05 ／ 実験できないときの工夫

くじ引きできない事件を解く知恵

「最低賃金を上げたら雇用は減るのか」「戦争が経済に与えた影響は」といった問題は、人を実験台にしてくじ引きで分けるわけにいかない。 こういうときは、社会の中でたまたまランダムに近い状況が生まれた場面（自然実験）を見つけて、それを利用する。

たとえば「県境をはさんで、片方の県だけ制度が変わった」というような状況があれば、 よく似た環境の2つのグループを、実験なしで比べることができる。

🔍 「くわしい」モードで、代表的な統計手法を4つ紹介します
🔍 くわしく（おとな向け）：代表的な手法
  • 差分の差分法（DID）：政策の前後・実施地域と非実施地域、それぞれの変化量の差を取ることで、共通のトレンドの影響を打ち消す
  • 操作変数法（IV）：原因候補には影響するが結果には直接影響しない「操作変数」を使って、交絡因子の影響を切り離す
  • 傾向スコアマッチング（PSM）：観測された特徴が似ている処置群・対照群のペアを作り、擬似的にランダム化に近い比較を行う
  • 回帰不連続デザイン（RDD）：「テストで60点以上は合格」のような、ある基準値の前後で人がほぼランダムに分かれる状況を利用する

これらはいずれも、RCTほど強力ではないが、「実験できない現実の問題」に対して、できる限り因果に近づくための工夫と言える。

FILE 06 ／ ワナ集

探偵がハマりがちな落とし穴

第二次世界大戦中、軍は「戦場から帰ってきた戦闘機の、弾痕が多い場所」を調べて、そこを補強しようとした。 しかし統計学者エイブラハム・ヴァルドは「それは間違いだ」と指摘した。

なぜなら、調査できたのは"帰ってきた"機体だけ。本当に危険な場所に弾が当たった機体は、 撃墜されて帰ってこられなかったからだ。弾痕が少ない場所こそ、実は補強すべき急所だった。

このように、「生き残った・成功した例」だけを見て判断してしまうワナを生存者バイアスと呼ぶ。 見えているデータの裏に、"見えていない失敗例"がないか、探偵は常に疑う必要がある。

🔍 「くわしい」モードで、関連するバイアスの分類を紹介します
🔍 くわしく（おとな向け）

生存者バイアスは、より一般的な選択バイアス（selection bias）の一種であり、分析対象に含まれるサンプル自体が、 すでに何らかの条件でふるいにかけられている場合に生じる。DAGの言葉では、原因と結果の両方に影響する変数（コライダー：collider）を 分析の際に条件づけてしまう（例：生存した機体だけに絞る）ことで、本来存在しない見せかけの関係が生まれるコライダー・バイアスとして整理される。

また、全体では正の関係があるのに、集団を分けるとそれぞれの中では逆の関係になるシンプソンのパラドックスも、 隠れたグループ構造（交絡因子）を見落とすことで起きる、代表的な統計的錯覚のひとつ。

FILE 07 ／ 実例

因果推論は、身の回りで大活躍している

因果推論は学問の中だけの話ではない。実はいろいろな場所で、日常的に使われている。

医療：新しい薬や治療法が本当に効くかを確かめる臨床試験は、RCTの代表例。

ビジネス：Webサイトのボタンの色をAとBの2パターンでランダムに出し分けて、どちらがクリックされやすいか比べる「A/Bテスト」も、小さなRCT。

教育：「クラスの人数を少なくすると学力が上がるか」を調べるために、学校をランダムに割り当てて比較する研究が行われている。

政策：最低賃金や税制の変更が雇用・消費にどう影響するかを調べるために、自然実験や差分の差分法が使われている。

🔍 「くわしい」モードで、分野ごとの代表的な設計手法を紹介します
🔍 くわしく（おとな向け）
  • 医療統計：二重盲検RCT、生存時間分析での傾向スコア調整
  • プロダクト分析：A/Bテストの検定力設計、ネットワーク効果がある場合のクラスターランダム化
  • 教育経済学：STAR実験（少人数学級の効果を調べた大規模RCT）などが有名
  • 労働経済学：最低賃金研究における州境を利用したDID分析（カード＝クルーガー研究が代表例）
FINAL FILE ／ まとめ

因果推論的に考える、4つのコツ

01

その関係、「一緒に動いている」だけかもしれない。相関と因果を区別する。

02

両方に影響している「かくれた黒幕（交絡因子）」がいないか疑ってみる。

03

原因と結果の矢印の向きが、逆になっていないか確かめる。

04

比べている2つのグループは、本当に公平な比較相手か考える。
